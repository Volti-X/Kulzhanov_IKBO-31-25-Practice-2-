# Инструмент визуализации графа зависимостей (Вариант №15)

Консольное CLI-приложение на языке C++, предназначенное для анализа зависимостей пакетов Ubuntu (apt) и построения графа. Проект выполняется поэтапно в рамках практической работы.

## Описание проекта
Инструмент получает данные о зависимостях заданного пользователем пакета из репозитория, строит граф зависимостей (с учётом транзитивности), обрабатывает циклические зависимости и поддерживает режим тестирования на локальных файлах.

## Этап 1: Минимальный прототип с конфигурацией
Программа поддерживает параметры командной строки:
- `--package <имя>` — имя анализируемого пакета (обязательно).
- `--repo <url_или_путь>` — URL-адрес репозитория или путь к локальному файлу (обязательно).
- `--mode <url|file>` — режим работы с репозиторием (по умолчанию `url`).
- `--version <версия>` — версия пакета (по умолчанию `latest`).
- `--output <файл>` — имя файла для сохранения графа (по умолчанию `graph.png`).
- `--filter <подстрока>` — подстрока для фильтрации пакетов.

При запуске выводится отладочная информация о переданных параметрах. Реализована обработка ошибок для обязательных параметров.

## Этап 2: Сбор данных
- Парсинг файла формата Ubuntu (`Packages`), поиск нужного пакета и его версии.
- Извлечение прямых зависимостей из строки `Depends:`.

## Этап 3: Основные операции (BFS)
- Построение графа зависимостей с учетом транзитивности (зависимости зависимостей).
- Использование алгоритма обхода в ширину (BFS) с очередью (`std::queue`).
- Обработка циклических зависимостей (защита от бесконечных циклов с помощью `std::set`).
- Фильтрация пакетов: игнорирование пакетов, имена которых содержат заданную подстроку (`--filter`).
- Поддержка режима тестирования на файлах с большими латинскими буквами (A, B, C, D).

## Этап 4: Дополнительные операции (Обратные зависимости)
- Поддержка режима вывода обратных зависимостей для заданного пакета.
- Поиск пакетов, которые зависят от указанного пакета, на основе уже построенного графа.

## Сборка и запуск
1. Откройте файл `dep_graph.sln` в Visual Studio 2022.
2. Нажмите `F5` для сборки и запуска.

## Тестирование
Для проверки работы программы используются локальные файлы в папке `tests`:
- `tests/test_packages.txt` — фрагмент реального репозитория Ubuntu с пакетами (для проверки парсинга).
- `tests/test_graph.txt` — тестовый граф с пакетами A, B, C (для проверки BFS и циклов).

**Пример запуска (режим тестирования с реальными данными):**
```
dep_graph.exe --package accountsservice --repo tests/test_packages.txt --version 22.07.5
```
**Пример запуска (тест BFS с циклом и фильтром):**
```
dep_graph.exe --package A --repo tests/test_graph.txt --filter D
```
